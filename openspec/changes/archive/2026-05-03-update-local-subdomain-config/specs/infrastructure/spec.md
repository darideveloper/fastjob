# infrastructure Specification Delta

## ADDED Requirements

### Requirement: Local Subdomain Support
The application MUST support the `fastjob.localhost` domain for local development to ensure environment isolation and RFC compliance.

#### Scenario: A developer accesses the app via fastjob.localhost
- **Given** the developer has configured their browser or proxy for `fastjob.localhost`
- **When** they navigate to `http://fastjob.localhost:8000` or `https://fastjob.localhost`
- **Then** the application MUST allow the request (included in `ALLOWED_HOSTS`).
- **AND** CSRF verification MUST succeed (included in `CSRF_TRUSTED_ORIGINS`).
- **AND** links generated by the application MUST use `fastjob.localhost` as the domain.
